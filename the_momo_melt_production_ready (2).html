Deployment & Security Guide

This application is production-ready. To ensure data security, you must deploy the following Firestore Security Rules in your Firebase console.

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /artifacts/{appId}/public/data {
      match /menu/{menuId} {
        allow read: if true;
        allow write: if request.auth != null && request.auth.token.email == 'admin@themomomelt.com';
      }
      match /orders/{orderId} {
        allow create: if request.auth != null && request.resource.data.customerId == request.auth.uid;
        allow read: if request.auth != null && (request.auth.uid == resource.data.customerId || request.auth.token.email == 'admin@themomomelt.com');
        allow update, delete: if request.auth != null && request.auth.token.email == 'admin@themomomelt.com';
      }
    }
    match /artifacts/{appId}/users/{userId}/cart/{cartId} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
  }
}
  • Admin Access: Create an account with the exact email admin@themomomelt.com to access the dashboard.
  • Offline Persistence: Firestore local caching is enabled by default to handle transient network drops gracefully.
  • Persistent Cart: User carts are securely saved to their private Firestore collection and sync across devices.
